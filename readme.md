# Blog App

A simple blog application built using **Node.js**, **Express**, and **EJS**.  
Users can create, view, edit, and delete blog posts with a clean and responsive UI powered by **Bootstrap**.


## Features

- Create new blog posts
- View individual posts
- Edit existing posts
- Delete posts
- Responsive layout (desktop & mobile)
- Server-side rendering using EJS templates


## Tech Stack

- **Node.js**
- **Express.js**
- **EJS**
- **Bootstrap 5**
- **Body-parser**
- **HTML / CSS / JavaScript**


## Installation and setup

1. **Clone the repository**
```
git clone https://github.com/Mannan-10/blog-app.git
```
2. **Navigate into the project**
```
cd blog-app
```
3. **Install dependencies**
```
npm install
```
4. **Run the server**
```
node index.js
```
5. **Open your browser and go to:**
```
http://localhost:3000
```
